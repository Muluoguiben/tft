# 图片素材说明

本目录用于存放项目 Markdown 文档中引用的图片素材。

## 推荐目录

- `items/`：装备图标，例如无尽之刃、蓝霸符、鬼索的狂暴之刃。
- `champions/`：弈子头像。
- `traits/`：羁绊图标。
- `comps/`：阵容图卡、站位图、成型截图。正式阵容图卡应同时展示阵容组成、站位、羁绊和关键棋子装备。
- `screenshots/`：个人实战截图和复盘截图。

## 使用规则

- Markdown 可以直接引用图片，例如：

```md
![无尽之刃](../../assets/items/无尽之刃.png)
```

- 图片旁边必须保留中文文字说明，不能只放图片。
- 阵容图卡建议命名为 `阵容名-patch-版本.png`，例如 `木灵小法师-17.1b.png`。
- 最终阵容图卡优先使用 `GPT Image2` 生成；SVG 或结构稿可以保留为同名源文件，方便后续修改。
- 装备、弈子和羁绊图片建议使用清晰中文文件名，必要时追加英文别名，例如 `无尽之刃-infinity-edge.png`。
- 优先使用仓库内图片，不依赖临时外链。
- 如果图片来自公开网站或游戏截图，尽量记录来源和获取日期。
