# Data

This folder is reserved for structured TFT-related data.

Current files:

- `comp-pool-2026-04-28.csv` - Initial S17 competition comp pool and qualitative scoring seed
- `daily-comp-review-template.csv` - Daily source review template for meta updates
- `training-log-template.csv` - Per-game practice log template

Possible future files:

- `champions.json`
- `traits.json`
- `items.json`
- `sets.json`
- `glossary.json`

Data in this folder should be easy to read, update, and reuse in future tools or documentation.
