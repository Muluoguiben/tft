# 机甲 Flex

适用版本：金铲铲 S17「星神」/ TFT Set 17 / 17.2 早期判断
阵容定位：8 级锁血，装备 Flex，T2 稳定兜底。

![机甲 Flex 一图流](../../assets/comps/full/mecha-flex-17.2-early.avif)

## 阵容组成

9 人口：超级机甲、厄加特、奥瑞利安·索尔、塔姆、易、卡尔玛、茂凯、阿卡丽、烬。

核心羁绊：霸天机甲、斗士、暗星、狂战士。


## 适玩条件

- 8 级机甲牌和四费牌来得多。
- 法装、物理装、肉装都能有人消化。
- 需要立刻锁血，不适合继续贪经济。
- 同行不多，至少一个主 C 能二星。

## 放弃条件

- 把 3 机甲当 6 机甲打，会高估上限。
- 装备太平均，没有一个主 C 成型。
- 前排一星，后排再强也启动不了。

## 装备

- 超级机甲：石像鬼石板甲、饮血剑、斯特拉克的挑战护手。
- 奥瑞利安·索尔 / 卡尔玛：珠光护手、灭世者的死亡之帽、朔极之矛。
- 厄加特 / 易：泰坦的坚决、饮血剑、鬼索的狂暴之刃。

## 运营节奏

- 2 阶段：用强前排和通用装备保血。
- 3-2：装备散就保留机甲 / 四费 Flex 口。
- 4-2：上 8 大搜，谁二星谁先吃装备。
- 后期：能补 6 机甲再冲，否则稳前四。

## 注意事项

- 机甲单顶，塔姆和茂凯分担第一波伤害。
- 龙王、卡尔玛、烬分散第四排。
- 找到 6 机甲条件后再转 6 机甲龙王。
