# S17 中文翻译对照

更新时间：2026-04-28

用途：记录 TFT Set 17 与金铲铲 S17「星神」相关的中文名，避免把英文羁绊直译成错误名称。阵容卡、图卡提示词和 GPT Image2 图卡都应优先使用这里的中文名。

完整资源基线见 `docs/S17资源基线.md` 和 `data/s17/`。后续新增阵容前，先查本对照表确认中文展示名，再查资源基线拿棋子、技能、装备、星神和图片路径。

## 木灵小法当前结论

当前 `docs/comps/木灵小法师.md` 采用的是你实战吃鸡的游侠手游一图流分支，阵容为小法、库奇、拉莫斯、波比、巴德、卡尔玛、菲兹、小木灵、丽桑卓，羁绊为：

- `7 木灵族`
- `2 魔术师`
- `2 暗星`
- `2 旅人`
- `2 堡垒卫士`

之前记录过的 `菲兹 + 锐雯` 分支会激活 `2 游侠`，但那不是你今天玩的这一套。后续如果要写锐雯分支，必须另建阵容卡或明确标注为另一分支，不能和当前木灵小法一图流混写。

## 图卡规则

- GPT Image2 生成前，必须先用本文件核对中文羁绊名。
- 当前木灵小法一图流图卡里不应出现 `游侠`、`锐雯`、`潜行`、`盗贼`、`堡垒`、`木灵` 这类旧占位或旧分支内容。
- 如果图卡中文名和 Markdown 冲突，以 Markdown 和本对照表为准。
