# S17 星神 4-7 恩赐与阵容适配

适用版本：TFT Set 17 / 金铲铲 S17「星神」，Patch 17.1 口径。
核对时间：2026-04-28。

## 核对结论

`/Users/bytedance/Downloads/tft_s17_space_gods_4-7_rewards.md` 这份表整体可用，9 个星神的 4-7 专属恩赐与项目内 `data/s17/star-gods.zh.json` 基本一致。

需要注意：

- 4-7 的前三格是通用宝库奖励，第四格才是信奉星神的专属恩赐。
- 通用宝库 `60% / 30% / 7% / 3%` 概率来自第三方系统表，官方只确认 4-7 是信奉星神的 Boon 武器库，并未在公告里展开完整概率表。
- 艾克的 `12 金币 + 12 金币 + 12 金币 + 异常突变 + 2 拆卸器` 只是通用宝库 roll 到 3% 三金币形态时的结果，不是艾克固定给 36 金币。
- 凯尔是随机把一件已完成装备升级为光明装备，不是自选光明装备。
- 锤石描述建议写成“每次玩家战斗后掷骰”或“每个玩家战斗回合后掷骰”，比“每回合掷骰”更清楚。

## 旧攻略冲突

早期攻略里有两处常见旧口径，后续写阵容卡时优先使用当前项目数据和 LoLChess 当前 Set 17 数据：

| 星神 | 旧口径 | 当前采用口径 |
|---|---|---|
| 阿狸 | 每回合获得 2 金币、2 经验、2 刷新 | 队伍获得 `2% × 等级` 的攻击力和法术强度；之后每回合获得 2 经验 |
| 韦鲁斯 | 每总星级 10 生命值，5 费概率 +4% | 每总星级 18 生命值，5 费概率 +2% |

## 比赛选择优先级

- 高血量高经济：优先阿狸、奥瑞利安·索尔、艾克，目标拉人口和提升上限。
- 中等血量要 4-2 锁血：优先凯尔、艾克、亚索，目标当回合战力。
- 低血量保前四：优先索拉卡、凯尔；伊芙琳谨慎选。
- 赌阵或追三星：优先韦鲁斯，其次凯尔、亚索。
- 没有明确方向但你能 flex：锤石可以选，但比赛里不要把它当稳定答案。
