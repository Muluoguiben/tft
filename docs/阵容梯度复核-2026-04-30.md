# 阵容梯度复核 2026-04-30

更新时间：2026-04-30

适用版本：TFT Set 17 / 17.2 第二天。金铲铲端内如果尚未同步 17.2，需要赛前以游戏内公告和实战环境再校准。

## 结论

冠军目标下，当前阵容池不能继续把木灵小法、木灵飞机、妖姬卡尔玛当默认主线。它们仍能吃分或吃鸡，但都需要明确条件。

当前主练顺序调整为：

1. `6机甲龙王`：OP 条件线，6 机甲、龙王法装和机甲坦装同时成立时优先。
2. `观星霞`：OP 物理主线，登顶上限高，但必须有攻速、破甲和安全观星格。
3. `牧羊维克托`：OP / T1 之间的高前四 AP 主线，适合 AP 装和前排早成型。
4. `海魔大卑`：OP 条件赌阵，开局胡、装备对、同行少时优先练。
5. `新星九五`：T1 上限线，只在高血量高经济时冲 9。

## 比赛阵容池

### OP 主线

- `6机甲龙王`：快 8 搜三机甲框架，目标 6 机甲；龙王法装和机甲坦装缺一不可。
- `观星霞`：有好观星效果、羊刀/无尽/轻语方向、努努前排质量时玩。
- `牧羊维克托`：AP 装多、前排早成型、维克托同行少时玩，目标稳定前四。
- `海魔大卑`：2 阶段海魔 / 新星胡，卑尔维斯装备对，3-2 能 D 出二星质量时玩。

### T1 备选

- `新星九五`：优势局上限线。4-2 能稳住且有钱上 9 才继续，不要低血贪。

### T2 条件线

- `妖姬卡尔玛`：AP 装兜底线，只有重装前排和妖姬/卡尔玛质量顺时进入。
- `木灵飞机`：木灵、经济、装备三条件同时满足才玩；否则转机甲 Flex 或九五。
- `机甲 Flex`：4 阶段锁血兜底，不把 3 机甲误当 6 机甲上限。
- `太空律动转`：有转职才玩，无转职直接降级。
- `幻灵阿萝拉`：高风险收菜武器，普通积分局不默认使用。
- `木灵小法师`：木灵/AP 胡牌线。默认快 8 找 7 木灵，不在 5/6 级硬 D。

## 执行规则

- 普通积分局优先选高前四阵容：牧羊维克托、海魔大卑、观星霞。
- 优势局或最后冲分局优先选高登顶阵容：6 机甲龙王、观星霞、新星九五。
- 同一核心 C 有 2 家以上同行且你不是最胡，直接转相邻体系。
- 4-2 低血大搜后如果主 C / 主坦仍不能二星，不继续幻想大成，优先转能锁血的 T2 兜底线。
- 木灵小法和木灵飞机必须写清楚“为什么这局能玩”，否则默认不玩。
