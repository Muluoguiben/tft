# 静态站点部署

更新时间：2026-04-29

本项目已经提供静态网页入口：`index.html`。它直接用 HTML / CSS / JavaScript 展示阵容组成、棋盘站位、装备、星神选择和运营节奏，不需要翻到 GitHub 图片页再放大查看。

## 本地查看

最简单方式：直接用浏览器打开仓库根目录的 `index.html`。

如果浏览器对本地文件路径限制较多，可以在仓库根目录启动一个静态服务：

```sh
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080/
```

## 文件结构

- `index.html`：静态站入口，首页展示 OP / T1 / T2 阵容梯度。
- `site.css`：页面样式，负责暗色电竞 UI、棋盘、卡片和响应式布局。
- `site.js`：阵容数据、梯度首页、筛选路由和详情页渲染逻辑。
- `_config.yml`：GitHub Pages 发布排除规则，避免把原始大图、脚本和数据源发布到线上。
- `assets/s17/`：本地棋子、羁绊、装备、星神图片。
- `assets/comps/preview/`：网页内加载的轻量一图流预览图。
- `assets/comps/full/`：点击查看的高清 JPG 图。

## 页面结构

- `#/`：阵容梯度首页，按 OP、T1、T2 分组展示多套阵容。
- `#/tier/OP`：只看 OP 阵容。
- `#/tier/T1`：只看 T1 阵容。
- `#/tier/T2`：只看 T2 阵容。
- `#/comp/woodland-veigar`：木灵小法师详情页，包含羁绊、站位、装备、星神、运营节奏和转阵出口。

首页不能只放单套阵容。新增阵容时，应先进入梯度首页，点击阵容卡后再进入详情页。

## GitHub Pages

如果用 GitHub Pages，可以在仓库设置中选择：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/root`

这样 `index.html` 会作为站点首页。

## Cloudflare Pages

如果用 Cloudflare Pages：

- Build command：留空
- Build output directory：`/`
- Root directory：仓库根目录

这个项目没有构建步骤，直接作为静态文件发布。

## 后续扩展

新增阵容时，优先把阵容数据沉淀到 Markdown 阵容卡，再同步到 `site.js`。不要只做图片版一图流；网页里必须展示：

- 阵容组成
- 棋盘站位
- 核心羁绊
- 主 C / 主坦 / 副 C 装备
- 推荐星神
- 适玩条件
- 放弃条件
- 运营节奏
- 转阵出口
