# GPT Image2 阵容图卡提示词模板

用途：把已经确定好的阵容卡内容交给 `GPT Image2`，生成一张“阵容组成 + 站位 + 棋子装备 + 过渡思路 + D 牌节奏 + 注意事项”的最终阵容图卡。

## 使用前提

- 必须先完成对应 `docs/comps/` 阵容卡。
- 不允许让图像模型自行编阵容、编装备、编羁绊或编数据。
- 不允许在图里写来源、网站名、URL 或参考出处；这些只写在 Markdown 阵容卡里。
- 生成后必须人工核对：棋子数量、站位方向、装备归属、羁绊档位、中文文字。

## 提示词

```text
请生成一张 16:9 横版 TFT / 金铲铲阵容图卡，风格参考高质量阵容模拟器界面，暗色电竞 UI，信息密度高但清晰可读。

重要要求：
1. 这是阵容总览图，不是宣传海报。
2. 图中必须同时展示：阵容组成、棋盘站位、羁绊、主 C 装备、主坦装备、副 C 装备、过渡思路、D 牌节奏、适玩条件和风险提示。
3. 棋盘站位必须从上到下按人类阅读顺序展示：前排在第一排或第二排，后排在第三排或最后一排。
4. 所有中文文字必须清晰，不要乱码，不要生成无意义符号。
5. 不要额外添加未提供的棋子、装备、羁绊或胜率数据。
6. 如果图标无法精确还原，请用清晰色块、中文名和小图标占位，但必须保证名称正确。
7. 画面里不要写来源、网站名、URL 或参考出处。

【填写阵容名】

适用版本：
【填写版本，例如 金铲铲 S17 / TFT Set 17 / 17.1b】

【填写运营、赌阵、快 9、转职限定、高上限、保分等】

强度标记：
【填写 S / A / B / 观察阵容等】

阵容组成：
【填写最终 8 人口和 9 人口棋子】

核心羁绊：
【填写关键羁绊和档位】

棋盘站位：
前排：【填写前排棋子】
第二排：【填写第二排棋子】
第三排：【填写第三排棋子】
后排：【填写后排棋子】

主 C：
【填写主 C 名称】
主 C 装备：
【填写 3 件核心装备和备选装备】

【填写 3 件核心装备和备选装备】

【填写 3 件核心装备和备选装备】

【填写 3 到 5 条】

【填写阵容失败时转什么】

底部运营节点：
【填写 2 阶段、3-2、4-2、后期的关键操作；不要写来源】
```

## 保存规则

- 生成后的最终图保存到 `assets/comps/阵容名-版本.png`。
- 如果有可编辑结构稿，保存为 `assets/comps/阵容名-版本.svg`。
- 对应阵容卡顶部引用 PNG，不直接引用临时外链。
