# TFT

This repository collects notes, guides, and structured content about **Teamfight Tactics (TFT)**.

Teamfight Tactics is Riot Games' auto-battler game mode based on the League of Legends universe. In China, players may also be familiar with **Golden Spatula**, a related mobile game published for the Chinese market.
